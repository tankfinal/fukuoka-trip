## ⚠️ 孕婦行程注意

| 景點 | 狀態 | 說明 |
|---|---|---|
| 阿蘇中岳火口 | ❌ **禁止** | 日本官方禁止孕婦進入（火山氣體 SO₂）|
| 草千里 | ✅ OK | 平坦草原，遠眺火山 |
| 柳川遊船 | ❌ 不搭 | 只吃鰻魚飯 |
| 別府地獄 | ✅ OK | 用看的，不下水，選 3 個就好 |
| 金鱗湖、由布院 | ✅ OK | 平坦散步 |
| 糸島白糸の滝 | ⚠️ 在下方休息 | 上瀑布要爬階梯 |
| 太宰府 | ✅ OK | 平緩 |
| 屋台 | ⚠️ 看狀況 | 冷天會冷、空氣差 |

### 孕婦必帶
- 母子健康手冊（中日文版）
- 健保卡
- 海外醫療險（**含懷孕條款**）
- 平日吃的維他命/藥
- 家附近婦產科聯絡方式
