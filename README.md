### 9 月孕婦特別注意

- 🌡️ **9 月日本仍熱**（福岡白天 28–30°C）：勤補水、戴帽子、室外活動別超過 1 小時就找冷氣休息
- 🚗 **長途車程**易水腫：Day 3、5、7 都有 2 hr+ 的高速段，每 1 小時下交流道休息站走 5 分鐘
- 👃 **別府硫磺味**懷孕對氣味敏感：地獄區單個 5–10 分鐘就走，不一次看 7 個
- 🍣 **食物禁忌**：生魚片、生牡蠣（糸島伊都菜彩會看到）、未煮熟雞肉、未殺菌乳酪、酒精料理一律 PASS
- ☕ **咖啡因**：星巴克太宰府店、B-speak 等只點低咖啡因或無咖啡因選項
- 👶 **人潮地點**（太宰府、湯之坪、運河城）走中央避免被撞肚子；連假首日太宰府特別擠
- 🩺 **緊急狀況**先打 119 或下方產婦科電話
