---

## ⚠️ 最重要警告：2026 年九州「白銀週 5 連休」

**2026/9/19–9/23 是日本 11 年來首次出現的「Silver Week 5 連休」**：
- 9/19（六）9/20（日）週末
- 9/21（一）**敬老日**
- 9/22（二）**國民休日**（被祝日夾住自動成假日，11 年來首見）
- 9/23（三）**秋分日**
- 加上 9/24-25 請假可能變成 9 連休

**對行程的影響：**
- 🚗 高速公路會極度塞車，從福岡到熊本/阿蘇/由布院的車程要**抓平常 1.5 倍**
- 🏨 熊本市、別府市飯店會搶手且漲價，**最晚 6/30 前要訂**
- 🍴 太宰府、柳川、由布院等熱門景點人爆滿
- ⛽ 高速 SA/PA、加油站可能排隊

**因應策略已內建在以下行程**：避開連假最尖峰日做長途移動、提早出發、預約必訂餐廳、訂飯店優先選有停車場的店。

## ⚠️ 孕婦行程注意

| 景點 | 狀態 | 說明 |
|---|---|---|
| **阿蘇中岳火口** | ❌ **全部人都不能去** | 2026/1/27 起因直升機事故全面關閉中，**草千里仍開放** |
| 草千里 | ✅ OK | 平坦草原，遠眺阿蘇五岳 |
| 大觀峰 | ✅ OK | 平坦展望台 |
| 柳川遊船 | ❌ 不搭 | 木船 70 分鐘無廁所、上下船有高低差 |
| 別府地獄 | ✅ OK | 用看的，不下水 |
| **地獄蒸し工房** | ⚠️ 看狀況 | 蒸氣熱、人多排隊，**孕婦可在外等不參加** |
| 金鱗湖、由布院 | ✅ OK | 平坦散步路 |
| 糸島白糸の滝 | ⚠️ 在下方休息 | 上瀑布有階梯，孕婦在水車食堂吃流しそうめん即可 |
| 太宰府 | ✅ OK | 平緩，本殿大改修可能已完工 |
| 中洲屋台 | ⚠️ 看狀況 | 沒廁所、座位窄、二手菸；孕婦可挑屋台村替代 |
